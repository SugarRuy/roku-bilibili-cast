# Roku小电视 v0.2.0（预发布版）

这是从 v0.1.7 升级的一批功能更新，继续通过 Roku 开发者模式侧载安装。
它尚不是完成全部稳定性验收的正式版，也不是 Roku 商店上架版本。

## 本次变化

- 名称改为「Roku小电视」，采用粉色小电视 Logo；默认粉色主题、黑体。
  已保存的字体、主题和登录状态继续保留。
- 优化视频列表首次滚动：在电视内准备并缓存标题／作者文字，提前请求页面，
  分批接入卡片，准备或图片加载失败时回退原生文字。
- 完善播放侧栏：弹幕开关置顶，增加字号、速度、密度、弹幕类型及本地关键词屏蔽。
- 点播支持自动／手选可用画质、偏好记忆、低档回退及切换失败恢复。
  继续使用最高 1080P AVC 路径，受视频和账号权限限制。
- 增加点赞、收藏、稍后再看和投币入口；投币需单独选择数量并确认。
- 实验性电视端后台投屏：先打开一次 App，在接收进程仍存活时，
  手机 B 站视频页可投屏唤回 App。无需常开的电脑桥接或额外手机 APK。

## 已验证

- 列表修复在 Roku TV M302X / OS 16.0.4.853 实测：
  首次下滑约 150–307 ms 的渲染事件间隔降到约 27 ms；
  快速上下移动、分页、当前两排文字显示及图片加载失败回退通过检查。
- 合并版本 `c43f064` 已安装，确认新名称、Logo、粉色主题、首页列表加载，
  登录状态保留。发布包的频道文件与该安装包相比仅 manifest 版本号不同。
- 通过 BrighterScript 检查（沿用 1104 排除项）及 ZIP 内容一致性检查。
- 后台投屏有原研究版本的真实手机成功记录，不能视为所有手机／固件通过验收。

## 已知限制与待验证

- 弹幕仍可能有用户观察到的约半秒级停顿，未宣称已修复。
- 列表仍有偶发约 47 ms 波动；首次准备 20 条标题约 1.7–2.4 秒。
  当前性能结果只覆盖这台电视，不能保证其它设备相同。
- 暂停切画质、分 P、投屏换视频、失败回退及两秒内进度恢复仍需完整回归。
- 弹幕设置持久化及账号互动的完整模拟响应验收尚未补齐；
  测试没有消耗用户账号的硬币。
- App 进程被系统回收后，手机不能发现该接收器；电视系统重启后需手动打开
  App。长期待机、内存压力、Android／iPhone 分别验收及新投屏名称复验仍待完成。
- 字幕、音轨和倍速暂未提供。

## 安装

下载附件 `roku-bilibili-cast-v0.2.0.zip`，在电视的 Roku 开发者安装页上传 ZIP。
不要上传 GitHub 自动生成的 Source code 压缩包。附件 `SHA256SUMS.txt`
用于核对下载文件完整性。

当前电视上已安装 `c43f064` 的用户已拥有相同功能；此次发布仅将频道版本号
从 0.1.7 调整为 0.2.0，无需为了功能重复安装。

## 版本约定

开发阶段用 `0.x.0` 标记一批功能更新，`0.x.y` 用于同一批功能的修复。
等核心播放、投屏、设置保存和升级兼容性具备并通过明确验收后，再考虑 1.0。
版本号表示改动批次；本版本在 GitHub 标记为 prerelease，稳定性以验证记录为准。
